## 常用术语

| 术语 | 准备资料时的含义 |
| --- | --- |
| FCL | 整柜，使用完整集装箱运输本票货物 |
| LCL | 拼箱，与其他货物共用集装箱空间 |
| CBM | 立方米，用于表示货物体积 |
| 毛重 | 货物及其包装的总重量 |
| ETD | 预计离开时间 |
| ETA | 预计到达时间 |
| 货好日期 | 货物预计可进入下一项约定操作的日期 |

记录计划时保留最近一次更新的时间。预计日期用于安排生产、交货和接货，具体操作要求与本票货物的承运安排对应确认。
