# Shipping preparation guide

A practical reference for preparing freight enquiries, comparing quotations and recording shipping plans. It includes a reusable enquiry template, a comparison checklist and common terms for people arranging international shipments.

[中文说明](README.zh-CN.md)

## Prepare a freight enquiry

Start with a shipment description that another person can understand without a follow-up call. Use the template below and mark unknown items as “to be confirmed”.

```text
Cargo description:
Packaging and package count:
Gross weight and unit:
Total volume and unit:
Package dimensions if relevant:
Cargo ready date:
Collection address if required:
Origin port:
Destination port:
Final delivery address if required:
Transport option to compare:
Required collection and delivery services:
Special cargo properties to discuss:
Items still to be confirmed:
```

Keep the destination port separate from the final delivery address. Explain whether the enquiry covers the international leg, collection, destination services or delivery to a named address.

Compare the price together with the included work and the proposed schedule. Ask the service provider to clarify whether each fee is per container, per shipment or charged using another unit.

## Record ports and schedules clearly

For each location, keep the port name, code and country together. If a quotation names a particular terminal or collection point, record it separately.

Keep the latest proposed departure and arrival dates with the date you received the update. Confirm operational deadlines with the team handling the shipment and tell the receiving party when the plan changes. Estimated dates support planning; actual delivery also depends on the progress of the shipment and destination arrangements.

## Common shipping terms

| Term | Meaning for shipment preparation |
| --- | --- |
| FCL | Full container load, using a complete container for the shipment |
| LCL | Less than container load, sharing container space with other shipments |
| CBM | Cubic metres, a unit used to describe cargo volume |
| Gross weight | The combined weight of the goods and their packaging |
| ETD | Estimated time of departure |
| ETA | Estimated time of arrival |
| Cargo ready date | The date when the cargo is expected to be available for the next agreed operation |

Use the actual carrier and service terms to confirm charging rules and operational responsibilities.
